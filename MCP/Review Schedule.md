## How the Forgetting Curve Works

Based on **Ebbinghaus Forgetting Curve**, information is lost over time without review. Spaced repetition at increasing intervals helps move knowledge into long-term memory.

### Review Intervals

| Review # | Interval | Description |
|----------|----------|-------------|
| 1st Review | **1 day** after learning | Catch initial rapid forgetting |
| 2nd Review | **2 days** after learning | Reinforce short-term memory |
| 3rd Review | **7 days** after learning | Transition to long-term memory |
| 4th Review | **14 days** after learning | Strengthen retention |
| 5th Review | **28 days** after learning | Cement into long-term memory |

### Retention Curve Formula

```
Retention = e^(-t / S)
```
Where:
- `t` = time elapsed
- `S` = relative strength of memory (increases with each review)
